
# CodeAlpha Internship Project - Rule-Based Chatbot

## Project Overview
This project is a simple rule-based chatbot developed using Python as part of the CodeAlpha Internship.

The chatbot interacts with users through text input and provides predefined responses based on specific keywords and messages.

It is a console-based application that uses basic Python concepts such as conditional statements, functions, loops, and input/output operations.

## Features
- Greets users with Hello or Hi.
- Responds to "How are you?"
- Introduces itself when asked its name.
- Responds to thank you messages.
- Provides predefined replies to user inputs.
- Handles unknown messages with a default response.
- Ends the conversation when the user types Bye or Goodbye.

## Technologies Used
- Programming Language: Python
- Code Editor: Visual Studio Code
- Interface: Command Line / Terminal

## Python Concepts Used
- if-elif-else statements
- Functions
- While loop
- User input and output
- String methods (lower and strip)

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python chatbot.py

5. Start chatting with the chatbot.
6. Type 'bye' or 'goodbye' to exit.
